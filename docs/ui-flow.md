# UI Screens & Navigation Flow

## Student Portal
- Landing → Login/OTP → Profile setup → PG search → PG details → Booking request
- Dashboard: Bookings, Rent, Food ratings, Complaints, SOS, Documents, Community

## Owner Portal
- Login → Business profile → Property onboarding → Listing management
- Dashboard: Bookings, Maintenance, Food menu, Rent tracker, SOS alerts

## Super Admin Portal
- Admin login → User management → PG verification → Review moderation
- Analytics, SOS monitoring, Compliance, Subscriptions, Ads management
