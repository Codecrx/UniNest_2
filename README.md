# UniNest

Full-stack hostel & PG management MVP with student, owner, and super admin portals.

## Structure

- `apps/web` — Next.js frontend
- `apps/api` — Node.js API (Express + Firebase Admin)
- `docs` — Firestore schema, API endpoints, UI flows, and deployment steps

## Quick start

```bash
cd apps/web
npm install
npm run dev
```

```bash
cd apps/api
npm install
npm run dev
```

Create a `.env` file in each app based on `.env.example`.
